# GEO 顾问（草稿）

这是 WorkBuddy 专家包的草稿，格式对齐 [专家文档](https://open.workbuddy.cn/docs/expert)。还没有提交。

上传前请把 `plugin.json` 里的 `author.email` 换成可联系的邮箱，并把 `.mcp.json` 的 `url` 换成已部署的 `https://<你的域名>/mcp`。`.example` 只是占位。

头像是 512×512 PNG，和连接器的指南针图标不是同一张图。技能目录由 `node integrations/workbuddy/build-zips.mjs` 从连接器技能复制进压缩包。
